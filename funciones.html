Sistemas Operativos · Ficha técnica

El software que administra cada recurso de la máquina.

Un sistema operativo es la capa que se coloca entre el hardware y los programas: reparte el procesador, cuida la memoria, organiza los archivos y traduce lo que el usuario pide en instrucciones que la máquina entiende.

01

Funciones principales

Todo sistema operativo, sin importar la plataforma, resuelve el mismo conjunto de tareas de fondo.

Gestión de procesos

Decide qué programa usa el procesador y por cuánto tiempo, alternando entre tareas para que todas avancen.

Gestión de memoria

Asigna espacio en RAM a cada proceso y lo libera cuando ya no se usa, evitando choques entre programas.

Gestión de archivos

Organiza la información en carpetas y archivos, controlando dónde se guarda cada dato en el disco.

Gestión de dispositivos

Coordina teclado, mouse, pantalla, impresora y demás periféricos a través de controladores (drivers).

Seguridad y control de acceso

Verifica usuarios, protege archivos con permisos y limita lo que cada proceso puede hacer.

Interfaz de usuario

Traduce las acciones humanas en instrucciones para la máquina, ya sea por ventanas o por comandos.

02

Características clave

Cualidades que determinan qué tan capaz, estable y flexible es un sistema operativo.

A

Multitarea

Ejecuta varios procesos "al mismo tiempo", repartiendo el procesador en fracciones de tiempo tan pequeñas que parecen simultáneas.

B

Multiusuario

Permite que distintas cuentas usen el mismo equipo o servidor, cada una con sus propios permisos y espacio.

C

Tiempo real

En sistemas críticos, responde a eventos dentro de un plazo garantizado, sin margen para retrasos.

D

Portabilidad

Puede adaptarse a distintas arquitecturas de hardware con el mínimo de cambios en su código.

E

Escalabilidad

Sigue funcionando bien aunque crezca el número de usuarios, procesos o dispositivos conectados.

F

Confiabilidad

Mantiene la integridad de los datos y se recupera de fallas sin perder información del usuario.
